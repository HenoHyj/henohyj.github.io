PythonHIP / ROCmCoding agentsProfiling

Keeping the experiment accountable

Built a workflow for HIP / ROCm kernel optimization that connects code generation, compilation, correctness checks, profiling, and supervised review. A predefined benchmark contract controls acceptance, and measured feedback drives the next iteration.

  • Separate candidate development from final correctness and performance acceptance.
  • Preserve the implementation and measurement evidence associated with each experiment.
  • Reuse AMD architecture knowledge and bottleneck-specific tuning rules.

Hardware-aware iteration

Applied the workflow to MoE, convolution, and VSA tasks, including cross-architecture adaptation to MI300X. The supporting vibeHIP work includes a real CLI worker, HIP compilation, correctness and timing checks, and compile-error recovery within a single worker session.

Results & scope

An actively developed prototype. Individual experiments are validated against their own benchmark contracts; automatic generation does not guarantee a faster kernel.
