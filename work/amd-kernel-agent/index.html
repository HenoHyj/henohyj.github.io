Kernel development and validation

Built a HIP / ROCm kernel optimization workflow that connects code generation, compilation, correctness testing, profiling, and human review. Predefined correctness and performance criteria govern acceptance, and benchmark feedback guides the next iteration.

  • Separate candidate development from final correctness and performance acceptance.
  • Preserve the implementation and measurement evidence associated with each experiment.
  • Reuse AMD architecture knowledge and bottleneck-specific tuning rules.

Hardware-aware iteration

Applied the workflow to MoE, convolution, and VSA tasks, including cross-architecture adaptation to MI300X. Target experiments measured 10% higher MoE performance than the official implementation, and 1.08× VSA speedup over an optimized internal baseline. The supporting vibeHIP work includes a real CLI worker, HIP compilation, correctness and timing checks, and compile-error recovery within a single worker session.

Results & scope

An actively developed prototype. Each experiment has predefined correctness and performance criteria; generated kernels are accepted only after validation.
