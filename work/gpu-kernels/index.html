Sparse attention

Combined VSA with Sol Attention to split selected blocks into exact computation and summary approximation. Implemented INT8 QK / FP8 PV HIP kernels, summary generation, and a second-stage routing path. The work focused on memory reuse and reducing both attention and preprocessing overhead.

  • Adapted the attention interface to externally supplied routes and CSR metadata.
  • Used controlled comparisons to evaluate routing storage, internal sorting, and zero-mass handling.
  • Adapted execution and memory layouts separately for MI300X and MI355X.

Convolution paths

For Conv1D, fused layout and precision conversion, cached packed weights, and decomposed transposed convolution by stride to avoid ineffective computation. For Conv2D, adjusted tile shapes to output channels and spatial dimensions, used vectorized layout conversion, and wrote directly into the target output layout.

  • Measured approximately 32% and 20% performance gains over MIOpen on the respective target workloads.
  • Removed output differences introduced by solution switching and checked bitwise consistency for the same input.

Communication and computation

Developed a MoE All-to-All path using chunked pipelines, asynchronous execution, and three-level buffering to overlap communication with computation. The target SP8 configuration achieved a reported 1.84× speedup over the original implementation.

Results & scope

Target-workload measurements reported in my resume. Attention uses quantized block-summary approximation; these are operator results, not an end-to-end model speedup.
