Rebuilding core operators

Implemented and benchmarked Grouped Swizzling GEMM and FlashAttention-2 using CUDA and Triton. The work used implementation comparisons to understand scheduling, data movement, and inference-oriented kernel behavior.

Making FP4 run on consumer hardware

Investigated NVFP4 GEMM compatibility on the RTX 5090 with CUTLASS, adjusted layouts and computation paths, and implemented CUDA bitwise FP4 encoding and decoding. Preallocated workspaces and enabled Tensor Core / TMA paths, reaching approximately 2× the BF16 baseline on the target workload.

Results & scope

Compared with a BF16 baseline on the target test workload; this is a kernel benchmark, not a universal model-inference speedup.
