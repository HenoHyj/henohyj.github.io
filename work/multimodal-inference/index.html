Routing requests

Deployed MiniMax H3 through vLLM-Omni on AMD GPUs. Fixed a fallback that ignored multi-replica configuration, then implemented workload-aware routing with load reservation, release, and rollback on errors. On the same dual four-GPU topology, the mixed long/short request test improved effective end-to-end throughput by 11.44%.

Fusing the execution path

Following the Sol-H3 design, combined QKV exchange and fused QKNorm / RoPE with the send layout. This reduced communication calls and intermediate tensor reads and writes. The fixed-shape compute-and-packing path measured 3.19× faster than the original path.

Stopping work safely

Adapted in-flight cancellation using shared-memory signals and coordinated rank exit. Also corrected nondeterministic audio decoding. In an eight-GPU test with 25% early cancellation, valid requests completed in 21% less total time, with audio and video output consistency verified.

Results & scope

Separate experiments: mixed requests on a dual four-GPU topology; a fixed-shape fusion benchmark; and an eight-GPU test with 25% early cancellation. The gains are not additive.
