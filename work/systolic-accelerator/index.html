Architecture and quantization

Implemented a matrix-multiplication core with switchable weight-stationary and output-stationary dataflows. Evaluated greedy 4-bit / 2-bit mixed-precision quantization for VGG16 and built an SFP module with lookup tables for nonlinear activation functions.

From simulation to hardware

Performed hardware–software functional verification on an RFSoC 4×2 Pynq FPGA board and ran an OpenROAD physical-design flow with a 130 nm process: synthesis, placement, and routing. The repository contains baseline, SIMD, reconfigurable-array, and integration milestones.
