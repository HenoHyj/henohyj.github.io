AMD 算子优化 Agent

让实验结论可以核对

独立开发 HIP / ROCm 算子优化流程，连接代码生成、编译、正确性验证、profiling 与监督审查。使用预设 benchmark contract 约束验收，以实测反馈驱动下一轮迭代。

  • 将候选开发与最终正确性、性能验收分开。
  • 保存每次实验对应的实现与测量证据。
  • 复用 AMD 架构知识与面向具体瓶颈的调优规则。

面向硬件的迭代

将流程用于 MoE、卷积和 VSA 场景，包括向 MI300X 的跨架构适配。配套 vibeHIP 工作已接通真实 CLI worker、HIP 编译、正确性和计时检查，并支持在同一次 worker 调用内修复编译错误。

结果与测试范围

持续开发中的原型。各项实验依据自己的 benchmark contract 验证；自动生成实现并不保证算子更快。
