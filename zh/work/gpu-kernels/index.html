稀疏注意力

结合 VSA 与 Sol Attention，将选中块区分为精确计算与摘要近似。实现 INT8 QK / FP8 PV HIP Kernel、摘要生成与二次分区路由，优化访存复用并降低注意力和预处理开销。

  • 将注意力接口适配到外部路由与 CSR 元数据。
  • 通过受控对照评估路由存储、内部排序与零质量行处理。
  • 分别适配 MI300X 与 MI355X 的执行结构和存储布局。

卷积执行路径

Conv1D 路径融合布局与精度转换，缓存预打包权重，并按步长分解转置卷积以跳过无效计算。Conv2D 路径按输出通道和空间尺寸调整分块，结合向量化布局转换与目标布局直接写回。

  • 对应目标负载上，较 MIOpen 测得约 32% 与 20% 的性能提升。
  • 消除 solution 切换导致的输出差异，验证相同输入下的逐位一致性。

通信与计算

开发 MoE All-to-All 路径，通过分块流水线、异步执行与三级缓冲实现通算重叠。在简历记录的目标 SP8 配置下，较原实现取得 1.84× 加速。

结果与测试范围
